技术栈详情（云服务器版）

前端 + 后端

  • Next.js 14 (App Router)
  • Tailwind CSS (样式)
  • Framer Motion (动画)
  • next-themes (主题切换)
  • Prisma (ORM)
  • NextAuth.js (认证)

服务器环境

  • Node.js 18+
  • PM2 (进程管理)
  • Nginx (反向代理 + SSL)
  • PostgreSQL (自建或云数据库)
  • 图片存储 (本地/阿里云OSS)

运维需要处理的事项

  • 服务器基础环境配置
  • Nginx + SSL (HTTPS) 配置
  • PostgreSQL 安装和维护
  • PM2 进程守护和自动重启
  • 数据库备份策略
  • 日志管理
