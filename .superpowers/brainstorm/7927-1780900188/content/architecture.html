技术栈详情

前端

  • Next.js 14 (App Router)
  • Tailwind CSS (样式)
  • Framer Motion (动画)
  • next-themes (主题切换)

后端

  • Next.js API Routes
  • Prisma (ORM)
  • NextAuth.js (认证)
  • Supabase (PostgreSQL + Storage)
